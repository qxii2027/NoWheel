NoWheel 是一个面向界面开发的 Agent Skill。它让 AI 先问再做、使用真实图标库，并复用经过验证的开源实现，而不是从头造一遍。

01

安装

ZIP 下载最新版本 v1.0.0 · SHA-256 ↓

从 GitHub 直接安装，无需 clone：

npx github:Qxii2027/NoWheel install --project .

或者 clone 后安装：

git clone https://github.com/qxii2027/NoWheel.git
node NoWheel/scripts/install.mjs --project .

需要 Node 18+，无需 npm install。

默认写入当前项目；加 --target all 安装到用户目录。

02

变化

  1. 先问

    先问，再动手。

    布局、动效、依赖、许可证。只要决策真的存在分歧，AI 会停下来给出选项。

  2. 图标

    用真图标。

    检测项目已有的图标库，搜索真实标识符，拉取官方 SVG。不画路径，不猜名字。

  3. 复用

    复用现成的。

    复杂功能从检索开始：Star、维护状态、许可证、源码。基于成熟实现改造，而不是重写。

03

原理

一个由 harness 加载的 SKILL.md。三个开关。两个零依赖 Node 工具。

任务→开关→icon-tool / oss-scout→代码

AI 读取开关状态，只在对应规则开启时调用工具，然后把结果写进你的项目。没有守护进程，没有数据库，不需要安装。

04

使用

重启 harness，然后提出界面需求。技能会自动生效。

控制面板

运行后在 127.0.0.1:4317 打开本地面板，三个开关分别控制：

node .agents/skills/nowheel/scripts/control.mjs

在安装技能的项目根目录执行；用户级安装用 ~/.agents/skills/nowheel/scripts/control.mjs。

  • ask决策前先问
  • icons图标工具链
  • oss开源复用

开关状态写入 skill.config.json，下次任务生效；命令行也可用 status / set / reset。

搜索真实图标：

node .agents/skills/nowheel/scripts/icon-tool.mjs search "arrow up" --prefix lucide

支持 Claude Code、Codex、Gemini CLI、Copilot、Cline、Cursor、Windsurf，以及任何读取 AGENTS.md 的 harness。
