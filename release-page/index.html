Don’t reinvent the wheel.

NoWheel is an agent skill for interface work. It makes the agent ask before deciding, use real icon libraries, and reuse proven open source instead of rebuilding it.

Install ↓ GitHub ↗

000°

01

What changes

  1. Ask

    Ask first.

    Layout, motion, dependency, license. When a decision is genuinely open, the agent stops and presents options.

  2. Icons

    Use real icons.

    It detects the icon set already installed, searches real ids, and fetches the official SVG. No hand-drawn paths, no guessed names.

  3. Reuse

    Reuse what works.

    Complex features start with a search: stars, maintenance, license, source. Adapt a proven implementation instead of rebuilding one.

02

How it works

One SKILL.md the harness loads. Three switches. Two zero-dependency Node tools.

task→switches→icon-tool / oss-scout→code

The agent reads the switches, calls a tool only while its rule is on, and writes the result into your project. No daemon, no database, no install step.

03

Install

From GitHub, no clone:

npx github:Qxii2027/NoWheel install --project .

Or clone and install:

git clone https://github.com/qxii2027/NoWheel.git
node NoWheel/scripts/install.mjs --project .

Node 18+. No npm install. Prefer a zip? Releases ↗

04

Use

Restart the harness, then ask for interface work. The skill applies on its own.

Toggle the three rules:

node .agents/skills/nowheel/scripts/control.mjs

Search real icons:

node .agents/skills/nowheel/scripts/icon-tool.mjs search "arrow up" --prefix lucide

Works in Claude Code, Codex, Gemini CLI, Copilot, Cline, Cursor, Windsurf, and anything that reads AGENTS.md.
